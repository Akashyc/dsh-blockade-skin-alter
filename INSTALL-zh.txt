全鲸封锁 · DSH 皮肤插件 1.0.3
================================

安装（本地目录安装）
--------------------
1. 把本目录放在任意位置（路径可以带空格，命令里加引号即可）
2. 在 DeepSeek Harness 里执行：
     plugin_manager install_bundle "/路径/dsh-blockade-skin-alter"
3. 完全退出客户端，再打开：
     macOS   Cmd+Q
     Windows 关闭窗口后确认托盘图标也退出
   （Cmd+R 只刷新页面，客户端模块可能仍是旧缓存）

装了原版「封锁橙」的，建议先卸载它，两张皮肤叠着用没意义。

使用
----
- 设置 → 全鲸封锁：主题色、星空背景、神经连线、节点脉动、自定义背景、轻量模式
- 字体跟随 DSH 设置 → 通用设置 → 字号大小 → 更多字体设置；推荐字体见 README
- 要停用皮肤：在插件管理里关掉本插件
- 控制台快捷操作：
     __blockadeAlter.hud.get()
     __blockadeAlter.hud.set({ accent: '#2EC4B6' })
     __blockadeAlter.hud.reset()

卸载
----
     plugin_manager remove_bundle @local/dsh-blockade-skin-alter

说明
----
- 纯客户端插件：只覆盖主题变量并注入样式表，不修改宿主代码，卸载后恢复原样
- 设置保存在浏览器 localStorage，卸载后可手动清除
- 和灵魂狭间（dsh-chara-soul）都装时主题色联动，只装一个时各管各的
